# maxflow — 最大流 / 最小割库（Python 3，仅标准库）

## 文件

| 文件 | 说明 |
|---|---|
| `maxflow.py` | 库本体：Dinic 算法，输出最大流值、最小割边集合、各边流量 |
| `bruteforce.py` | 参考实现：Ford-Fulkerson 暴力增广（仅用于对拍） |
| `stress_test.py` | 对拍脚本：随机小图上两种实现的流值/割容量必须一致 |
| `test_degenerate.py` | 退化与边界用例集（unittest） |
| `benchmark.py` | 稀疏 / 稠密 / 二分匹配 / 分层网络耗时测试 |
| `example.py` | 用法示例 |

## 算法与复杂度

Dinic 算法：BFS 构建分层图 + DFS 求阻塞流（当前弧优化）。

| 网络类型 | 复杂度 |
|---|---|
| 一般图 | O(V² · E) |
| 单位容量图 | O(E · √V) |
| 二分匹配 | O(E · √V) |

实现要点：
- **反平行边**：每条原始边独立建一对残量边，u→v 与 v→u 互不干扰。
- **自环 / 零容量边**：允许存在，分层图中不会被使用，不影响结果。
- **超大容量**：Python int 任意精度，内部 INF 取所有容量之和（有限整数），
  已验证 2×10¹⁸ 无溢出。
- **s == t**：按约定返回流值 0 与空割。
- **最小割**：最大流后在残量网络上从 s 沿正残量边可达的点集为 S，
  割边集合 = 所有 S→T 的原始正容量边；割容量 = 最大流值（对偶性，
  对拍与单测中强制校验）。

## 耗时数据（Python 3.12，单次最优值）

稀疏网络（E ≈ 4V）：

| V | E | 耗时 |
|---|---|---|
| 10,000 | 39,994 | 71 ms |
| 50,000 | 199,994 | 1.29 s |
| 100,000 | 399,996 | 2.64 s |

稠密网络（E ≈ 0.5·V²）：

| V | E | 耗时 |
|---|---|---|
| 300 | 44,670 | 55 ms |
| 700 | 244,600 | 536 ms |
| 1,200 | 719,366 | 1.98 s |

完全稠密（E = V(V−1)）：n=200 → 32 ms；n=400 → 247 ms。

二分匹配（单位容量，p=q=5000，E≈110k）：217 ms，匹配值 5000。

分层对抗网络（L=10, 宽=200，E=360k）：559 ms。

结论：随机稠密图上 Dinic 实际表现远优于 O(V²E) 上界（分层轮数极少）；
稀疏大图瓶颈在建图与 BFS，10 万点 / 40 万边约 2.6 s。

## 退化用例覆盖

`test_degenerate.py` 共 13 例：反平行边（含环流抵消）、自环（源/中间/汇）、
零容量边、容量为零的源出边、超大容量（10¹⁸ 不溢出）、大容量小瓶颈、
源汇相同、无路径、单边、单点、完全二分网络（K₄,₅，流=割=min(Σa,Σb)）、
随机对偶性抽查（流值 ≡ 割容量）。

## 对拍说明

`stress_test.py` 每轮生成 n∈[2,8]、m∈[0,3n] 的随机图（含自环、反平行边、
15% 零容量边、偶发 10¹² 大容量），校验：

1. Dinic 与暴力增广的最大流值一致；
2. 两者最小割容量一致，且各自等于流值；
3. 割边集合合法（全部 S→T，容量和 = 流值）；
4. Dinic 的流满足容量约束与流量守恒。

默认 20,000 轮全部通过。
